# CodeAlpha_ImageGallery
A responsive image gallery built with HTML, CSS, and JavaScript featuring a lightbox preview with next/previous navigation.
.

🚀 Features
Responsive image grid layout
Hover zoom effect on images
Lightbox popup view
Next / Previous navigation
Close button for exiting preview
Smooth and simple UI
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
